# Macao LRT Web App

A React + Vite website for Macao Light Rapid Transit (LRT) information, with station details, route planning, fare lookup, and bilingual support.

## Live Site

- https://jasonchongcnh.github.io/lrt-web-app/

## Features

- Station list and station detail pages
- Route planning between stations
- Fare query with ticket type options
- Traditional Chinese / English UI
- Timetable data and translation support
- Station images and branding assets
- Leaflet + OpenStreetMap map view

## Tech Stack

- React 19
- Vite 7
- React Router
- Leaflet
- Tailwind CSS
- Lucide React
